# 장난감 시제품

장난감들이 먼지를 치워 침대를 지키는 게임의 시험판입니다. Android 전용입니다.

**[앱 파일(APK) 받기](../../releases/latest)**

## 설치하는 순서

1. 위의 링크를 열고, 아래쪽 **Assets**에서 `toyproto-0.0.1-proto.apk`를 누릅니다.
2. "해로울 수 있는 파일"이라는 경고가 나오면 **무시하고 다운로드**를 누릅니다.
3. 내려받기가 끝나면 **열기**를 누릅니다. "이 출처의 앱 설치"를 묻는 화면이 나오면 **허용**으로 바꾸고 뒤로 돌아옵니다.
4. **설치**를 누릅니다. 한 번 더 경고가 나오면 **무시하고 설치**를 누릅니다.

## 알아 둘 것

- 재미가 있는지 확인하려고 만든 시험판입니다. 스테이지는 6개이고, 지도 화면 아래의 두 단추로 두 가지 판(길 하나, 줄 셋)을 바꿔 가며 할 수 있습니다.
- 광고도 저장도 없습니다. 앱을 끄면 진행한 것이 사라집니다.
- 무엇을 눌렀는지가 기기 안에만 기록됩니다. 앱은 인터넷 권한을 포함해 아무 권한도 요청하지 않으며, 기록을 밖으로 보내지 않습니다.
- 64비트 Android 폰에서 됩니다. 실제 기기는 Galaxy Note20 한 대에서만 확인했습니다.
- 시험용(디버그) 서명으로 만든 파일입니다. 정식 출시본이 아닙니다.
